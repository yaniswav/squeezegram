5. FFmpeg - NOT included, downloaded by the user's action
================================================================================

Neither the installer nor the portable zip contains FFmpeg. squeezegram runs
ffmpeg.exe and ffprobe.exe as separate processes (it does not link to FFmpeg
libraries) and obtains them in one of two ways:

  a) The user presses "Download ffmpeg (LGPL)" in the app. squeezegram then
     downloads one pinned file, checks its SHA-256 and unpacks it into
     %LOCALAPPDATA%\squeezegram\sidecars. Nothing is downloaded without this
     action. The file is an unmodified build of the BtbN FFmpeg-Builds project
     (release autobuild-2026-10-22-13-06), hosted by the squeezegram project on
     its own GitHub release "ffmpeg-n9.0.2-33", together with its
     corresponding source (below).

       File:    ffmpeg-n9.0.2-33-g4cf298e66a-win64-lgpl-9.0.zip
       URL:     https://github.com/yaniswav/squeezegram/releases/download/ffmpeg-n9.0.2-33/ffmpeg-n9.0.2-33-g4cf298e66a-win64-lgpl-9.0.zip
       Size:    171482264 bytes
       SHA-256: ebc6e5d6c51856b402c347f0c4cfca70c4bc43c85f7b1148237b92742d81d16f

  b) The user points the app to an FFmpeg they obtained themselves. That
     build, and its licence, are then the user's responsibility.

Licence of the pinned build. It is the "lgpl" variant: configured with
--enable-version3 and without --enable-gpl or --enable-nonfree, hence licensed
under the GNU Lesser General Public License version 3 (the LICENSE.txt inside
the archive is the LGPL-3.0 text; https://www.gnu.org/licenses/lgpl-3.0.txt;
see also https://ffmpeg.org/legal.html). The app never downloads a GPL build.
It includes the H.264 encoder libopenh264 (Cisco, BSD-2-Clause,
https://github.com/cisco/openh264) and other libraries under their own
licences; the build scripts below list them.

Corresponding source of the pinned build:

  - FFmpeg: commit 4cf298e66a20dd90e8b7c62333ab5812596835ec (release n9.0.2 plus
    33 commits), archive ffmpeg-source-4cf298e66a.tar.gz on the same
    squeezegram release, also at
    https://github.com/FFmpeg/FFmpeg/tree/4cf298e66a20dd90e8b7c62333ab5812596835ec
  - Build scripts, patches and the list of bundled libraries with their
    versions: BtbN FFmpeg-Builds commit
    937868360a21d711ec94a33f5591d345ad9b7754 (tag autobuild-2026-10-22-13-06),
    archive ffmpeg-builds-scripts-9378683.tar.gz on the same squeezegram
    release, also at https://github.com/BtbN/FFmpeg-Builds

6. Not distributed with squeezegram
================================================================================

  - Microsoft Edge WebView2 Runtime and the Microsoft Visual C++ Redistributable
    (x64) are required on the target machine. They are not part of the installer
    or the zip. The installer asks Microsoft's own bootstrapper to install the
    WebView2 Runtime when it is missing.
  - tdl (AGPL-3.0) was only a development tool of the project and is part of no
    build.
  - Development and build tools (compilers, bundlers, linters, test tools) are
    not distributed, except for the traces they leave in the output files that
    are credited above (for example the Tailwind CSS notice in the stylesheet).
